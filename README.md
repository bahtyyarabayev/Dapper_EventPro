# Dapper_EventPro
Bu proje, **ASP.NET Core 6.0 Web API/MVC** ve **Dapper ORM** kullanılarak geliştirilmiş, yüksek performanslı bir etkinlik yönetim ve veri analiz platformudur. Proje, özellikle büyük veri setleri (Big Data) üzerinde hızlı veri işleme ve görselleştirme yeteneklerini sergilemek amacıyla tasarlanmıştır.
